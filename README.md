# homebrew-tap

Homebrew formulae for my own tools.

```bash
brew install faizanashiq/tap/caliper
```

| Formula | What it is |
| --- | --- |
| [caliper](https://github.com/FaizanAshiq/caliper) | A macOS menu bar app that measures distances on screen in logical points |

Everything here builds from source on your machine rather than shipping a binary, so
nothing arrives quarantined and first launch is clean.
