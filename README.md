# homebrew-tap

Homebrew formulae for my own tools.

```bash
brew install faizanashiq/tap/tinysnap
```

| Formula | What it is |
| --- | --- |
| [tinysnap](https://github.com/FaizanAshiq/tinysnap) | A macOS menu bar screenshot app: capture, mark up, redact, frame and pin |

Everything here builds from source on your machine rather than shipping a binary, so
nothing arrives quarantined and first launch is clean.
